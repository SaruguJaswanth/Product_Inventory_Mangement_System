📦 Product Inventory Management System (Python)
🔹 Overview
This is a menu-driven Python application designed to manage product records efficiently. It uses Pandas for CSV operations and Python’s built-in JSON module for JSON handling. The project demonstrates practical data management skills, including file operations, error handling, and structured program design.
🔹 Features
Add Product → Insert new product details into products.csv.
Display Products → View all products stored in the CSV file.
Update Product → Modify price and stock for an existing product by Product ID.
Delete Product → Remove a product record by Product ID.
Export to JSON → Convert CSV data into JSON format (products.json).
Display JSON → Read and print JSON data using the native json module.
Exit Option → Cleanly terminate the program.
🔹 Data Schema
Each product record includes:
Product ID
Product Name
Category
Price
Stock
🔹 Tech Stack
Python 3.12.10
Pandas (for CSV operations)
JSON module (for JSON handling)
🔹 Learning Outcomes
Hands-on experience with Pandas DataFrames for CRUD operations.
Understanding of CSV and JSON file handling in Python.
Implementation of a loop-based menu system with error handling.
Practical application of data validation and persistence.
---
👉 This project is ideal for beginners in Python and data management, showcasing how to build a simple yet functional inventory system.
